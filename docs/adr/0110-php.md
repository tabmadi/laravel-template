# ADR-0110: PHP

- **Status:** Accepted
- **Decides:** The Laravel app and its checks use PHP 8.5 from the pinned Nix input.

## Context

The app needs a PHP runtime for Artisan, HTTP requests, and tests. The PHP line also sets the syntax the formatters accept.

## Decision drivers

1. **Support.** PHP receives bug fixes and security fixes.
2. **Framework fit.** Laravel 13 lists the runtime as supported.
3. **Tool fit.** The runtime is available in Nix and runs the app tools.

## Considered options

| Option | 1 Support | 2 Framework fit | 3 Tool fit | Verdict |
| --- | --- | --- | --- | --- |
| PHP 8.4 | Active support through 2026 | Listed for Laravel 13 | Runs PHPUnit 13 and Laravel | Good for a project with a PHP 8.4 host |
| **PHP 8.5** | Active support through 2027 | Listed for Laravel 13 | The Nix pin runs Composer, Pint, Larastan, and PHPUnit | **Chosen** |
| PHP 8.6 | A newer runtime with a longer support window | Outside the published Laravel 13 support table | Available at the Nix pin | Revisit after the framework lists support |

### Sources

- [PHP supported versions](https://www.php.net/supported-versions.php) and [Laravel 13 support policy](https://laravel.com/docs/13.x/releases#support-policy).
- [PHPUnit supported versions](https://phpunit.de/supported-versions.html) and [Nixpkgs PHP builders](https://nixos.org/manual/nixpkgs/unstable/#sec-php).

## Decision

The dev shell and checks use `pkgs.php85`. The Composer manifest accepts the 8.5 line and requires the SQLite PDO extension.

## Consequences

The code can use PHP 8.5 syntax. A change to the PHP line also changes the Composer constraint and the Blade format target.

## Rules

- The Nix runtime, Composer requirement, and Blade target use the same PHP line.
- Composer checks the runtime and its extensions against the lock. `(CI: lint-php)`
