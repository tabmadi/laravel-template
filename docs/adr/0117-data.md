# ADR-0117: Local data and persistence

- **Status:** Accepted
- **Decides:** The sample uses a local SQLite file and writes notes through an Eloquent model.

## Context

A note should survive a restart of the app. A fresh project should be able to save one without a database server.

## Decision drivers

1. **Setup.** A developer can start the app with the dev shell.
2. **Persistence.** The app keeps notes across restarts.
3. **Fit.** The data access code suits a small Laravel app.

## Considered options

### Database

| Option | 1 Setup | 2 Persistence | 3 Fit | Verdict |
| --- | --- | --- | --- | --- |
| SQLite in memory | No separate service | Data ends with the connection | Good for isolated tests | Chosen for tests in [ADR-0113](0113-tests.md) |
| PostgreSQL | Needs a service and a connection | Stores data across app restarts | Good for a shared database with concurrent writers | Good when the project needs a database server |
| **SQLite file** | The app opens a local file | Stores data across app restarts | Good for a local sample app | **Chosen for development** |

### Data access

| Option | 1 Setup | 2 Persistence | 3 Fit | Verdict |
| --- | --- | --- | --- | --- |
| Raw SQL | Uses a framework connection | Writes to the same database | Gives direct control of SQL | Good for a database-specific query |
| Laravel query builder | Part of the framework | Writes to the same database | Expresses queries without a model | Good for data that needs no model behavior |
| **Eloquent** | Part of the framework | Writes to the same database | Holds model fields and supports pagination and relations | **Chosen for the note model** |

### Sources

- [SQLite use cases](https://www.sqlite.org/whentouse.html) and [Laravel database configuration](https://laravel.com/docs/13.x/database).
- [Eloquent](https://laravel.com/docs/13.x/eloquent), [Laravel query builder](https://laravel.com/docs/13.x/queries), and [Laravel migrations](https://laravel.com/docs/13.x/migrations).

## Decision

The app opens `database/database.sqlite` by default. The setup task creates that file if it is missing and runs the migration. An Eloquent model reads and writes notes.

## Consequences

The default database lives with the local project. A project with shared or concurrent writes can choose a server database and verify its own queries there.

## Rules

- The local database file stays out of git.
- The sample migration and writes run in the feature suite. `(CI: test)`
